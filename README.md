## About

Unity·C# 기반 XR·AR·피트니스 콘텐츠를 상용화해 온 개발자입니다. 센서 입력을 게임 로직·애니메이션·서버 통신으로 연결해, 사용자가 직접 움직이고 학습하는 콘텐츠를 만듭니다. 현재는 **언어재활 SaMD** 제품에서 Next.js/React 클라이언트와 MediaPipe 손 추적, 임상 지표 저장 흐름을 개발하고 있습니다.
